
The instrument always has 2 oscillators producing sound. To each oscillator, we can add *one* of: a sawtooth wave, triangle wave (both switches engaged), or pulse wave.
- If we add a pulse wave, then we can control the width of the wave with the Pulse Width knob

# OB-Xd Documentation
In OB-Xd, Oscillator 1 modulates Oscillator 2 (Frequency Modulation)

## Sections
### Oscillators
The knobs here have to do with the timbre of the note

Osc1 controls the general frequency (pitch) of the tone

### Filter
Mix - This knob allows us to transition between filter (EQ) behaviors: at the extreme counter-clockwise position, we have a low-pass filter. At the extreme clockwise, we have a high-pass filter. If the BP (Bandpass) switch is disengaged, then we have a notch. If BP switch is engaged, then we have a bandpass.
![](/assets/images/2025-02-13-11-34-16.png)

- LP24 - this switch modifies the MIX switch
    - The BP switch is disabled when this switch is engaged

### Mod LFO
The knobs here have to do with the modulation (ie. how the note changes over time) of the sound.
